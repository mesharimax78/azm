# عزم — Azm

تطبيق لتسجيل التمارين يشتغل من المتصفح ويتثبّت على الجوال.

- بدون حساب ولا تسجيل دخول.
- كل البيانات (التمارين، الوزن، الصور) تبقى على جهاز المستخدم فقط.
- يشتغل بدون إنترنت بعد أول فتح.

**التثبيت على الآيفون:** افتح الرابط في Safari ← زر المشاركة ← "إضافة إلى الشاشة الرئيسية".
**التثبيت على أندرويد:** افتح الرابط في Chrome ← "تثبيت التطبيق".
